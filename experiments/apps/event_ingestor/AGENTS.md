Project Instruction
===================


Tech Stack Required
-------------------

* Programming Language: Python `>=3.14`
* Web Framework: `FastAPI`

Code Style
-----------

* pep 8 
* Always add typing
* DO NOT add doc-string on top of python module


Architecture
-------------

* Hexagonal Architecture or Port/Adapter 
* MVC architecture mixed with Hexagonal Architecture
* Hexagonal Architecture MUST NOT follow the typical `apps`, `domain`, `infrastructure` but should be much ligher
* Avoid over complicated abstractions with Hexagonal Architecture

### Code Structure

* `src`: Source code of the application.
* `tests`: Where all tests will go.


### Plan

* Plan are meant to be saved in workspace for later raference.
* Plan names should be prefixed with the current plan count starting at `1` example `01-title.plan.md`


Answers
-------

* responses should be concise and brief as much as possible.
